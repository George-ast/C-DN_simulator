Базові поняття CDN

Origin Server (Сервер-джерело)

Основний сервер, де зберігаються першоджерела файлів сайту, база даних і виконується бізнес-логіка.

Edge Server / POP (Крайовий вузол)

Сервер CDN, розташований фізично близько до користувачів (у великих містах по всьому світі) для роздачі кешу.

Cache HIT vs Cache MISS

HIT: файл знайдено в кеші Edge і відразу віддано.
MISS: файлу немає в кеші, Edge запитує його у Origin.

DDoS Захист & Anycast

CDN розподіляє паразитний трафік по сотнях серверів, не допускаючи падіння основного Origin-сервера.
